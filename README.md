# Only One Pen

«One pen. No undo.»

「色だけを選んで描く」ことだけができる、ミニマルなお絵描きWebアプリ。

- ペンは1種類、太さは固定（`PEN_SIZE = 5`）
- 消しゴムは別モード、サイズも固定（`ERASER_SIZE = 22`）。1回では消えず、重ねるほど薄くなる
- **Undo / Redo は存在しない。レイヤーも図形ツールも存在しない。**
- PNG保存のみ。サーバー保存は行わない。

## 使い方

```bash
npm run dev     # http://localhost:5173 で確認
npm run build   # dist/ に静的ファイルを出力
```

依存ライブラリはゼロ。`index.html` / `style.css` / `app.js` の3ファイル構成で、そのまま静的ホスティングに配置できます。

## 制約（守るルール）

新機能を追加する際は「Only One Penの制約を壊さないか」を基準に判断します。
ペンサイズ変更、ブラシ選択、Undo/Redo、レイヤー、筆圧設定、高度な画像編集は追加しません。

描画エンジンは `app.js`、UI は `index.html` に分離してあり、将来 React 等へ移行する場合もそのまま差し替えできます。
